# دليل مركز التحكم — El Marakby Import Control Tower

## الهدف

تمت إضافة تبويب **Control Center — مركز التحكم** لتجميع أدوات التشغيل والإدارة في مكان واحد، مع الحفاظ على الوحدات الحالية وسجل التدقيق والنسخ الاحتياطي.

## تحرير الشحنات الحالية

1. افتح **Control Center**.
2. من **Shipment Editor** اختر رقم الشحنة.
3. عدّل المورد، الوصف، المنشأ، ETA، القيمة، الكيان، وسيلة النقل، الأولوية، المرحلة، حالة ACID، رقم ACID والملاحظات.
4. اضغط **Save Shipment Changes**.
5. سيتم تحديث Dashboard وTracker والفلاتر والإجراءات، ويُسجّل التعديل في Audit & Governance.

رقم الشحنة لا يمكن تغييره من المحرر حتى لا تنكسر روابط المستندات والتكاليف وسجل ACID.

## الفحص قبل التشغيل

اضغط **Run Health Check** لمراجعة:

- أرقام الشحنات الفارغة أو المكررة.
- الموردين غير المسجلين.
- القيم المالية غير الصحيحة.
- حالات ACID التي تقول Issued بدون رقم.
- مراحل Pipeline غير الصالحة.

## النسخ والاستعادة

- **Download JSON Backup**: النسخة الوحيدة القابلة للاستعادة الكاملة.
- **Restore JSON Backup**: استعادة قاعدة البيانات بعد اختيار ملف JSON.
- **CSV Exports**: للتقارير والتحليل في Excel، وليست بديلًا عن JSON Backup.
- **Download Entry Template**: نموذج CSV لبدء تجهيز بيانات شحنات جديدة.

يفضل أخذ نسخة JSON قبل أي استيراد أو تعديل جماعي أو تنظيف للبيانات.

## Module Control Board

يوفر وصولًا مباشرًا إلى:

- Dashboard
- New Shipment
- ACID / NAFEZA
- Gate Check
- Documents
- Customs
- Suppliers
- Costs
- Action Center
- Audit
- Reference / Data Management

## قواعد الأمان

- التعديلات محفوظة في قاعدة المتصفح الحالية.
- العمليات الحساسة مثل المسح الكامل أو Factory Reset لا تعمل بدون تأكيد صريح.
- الأرشفة لا تحذف السجل المرتبط.
- كل تعديل يتم تسجيله في Audit عند استخدام الأدوات المخصصة لذلك.
- النسخة الحالية ما زالت أداة متصفح أحادية المستخدم؛ لا تعتبر قاعدة بيانات مشتركة أو نظامًا تنظيميًا مركزيًا قبل إضافة Backend وAuthentication وRBAC.
