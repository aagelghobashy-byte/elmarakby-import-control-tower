⚙ Data Management
▼
All data in this system (shipments, suppliers, ACID log, gate checks, documents, customs, GRN, costs, tracker notes) is saved automatically to your browser's persistent storage and reloads every time you open this file — nothing is lost between sessions. Use the tools below when you need to remove, back up, or restore data.
📦 Recommended: take a full backup regularly
Storage lives in your browser profile. If you clear browser data, switch computers, or something goes wrong, an exported backup is the only way to fully restore everything. Download one after every major update (new shipment batch, new suppliers, etc).
To delete one record at a time: click the red ✕ button on any row in the Dashboard, Suppliers, or ACID Log tables. To wipe just the shipment list and start registering real shipments from zero, use "Clear All Shipments" on the Dashboard tab — your Supplier database and ACID log are kept. CSV exports are for viewing in Excel; the JSON backup is the only format that can be fully restored back into this system.
