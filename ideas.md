# Visual Direction — Clear Steel Operations

## Theme Name

Clear Steel Operations

## Direction

Preserve the industrial steel identity while making the control tower easier to scan during operations. The redesign uses a calmer navy/slate canvas, brighter text contrast, restrained amber for primary actions and warnings, cyan for information, and green/red only for state semantics.

## Principles

- Readability before decoration.
- One strong action color: amber.
- Status colors retain their meaning and are not used as general decoration.
- More breathing room around operational controls.
- Stronger grouping between navigation, KPIs, alerts, forms and data tables.
- Preserve the existing modules, labels, data model and workflows.

## Layout

Keep the current single-page control-tower layout and tab navigation. Improve hierarchy through larger readable text, clearer section headers, stronger card separation, better table row contrast, and mobile-safe horizontal scrolling.

## Typography

Retain Noto Sans Arabic for interface text and JetBrains Mono for identifiers, dates and numeric operational values. Raise the base size and secondary text contrast without changing data semantics.

## Interaction

Keep all existing interactions. Add no new business behavior. Improve visible hover, focus, active, disabled and selected states only through CSS.

## Palette

- Canvas: deep navy/slate.
- Panels: blue slate with clear surface separation.
- Primary: warm steel amber.
- Information: readable cyan.
- Success: green.
- Critical: red.
- Body text: cool white; secondary text: high-contrast slate.
